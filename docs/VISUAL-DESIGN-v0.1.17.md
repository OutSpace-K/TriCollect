# v0.1.17 艺术字与彩色玩具瓶仓

## 字形和动画

三个字使用定制Canvas笔画。转字采用粗笔画、斜切横画与窄高光，左右部件留出间隙；不再使用系统粗体字。个字的点按装饰时间计算完整一周竖轴转动，每个路径点经cos/sin与透视除数投影，中心竖画保持竖直，侧面有厚度暗边；不是Canvas平面rotate。球字的王偏旁和求部件本身使用弯曲笔画组织圆球外形，不包含额外圆弧边框、裁切圈或圆底。

9秒周期中1.6秒翻转，其余保持正面。后台、弹窗暂停装饰时间，不影响游戏计时。

## 玩具

五类小物有发条钥匙/鸭嘴/翅膀，火车车窗/烟囱/连杆轮，蜗牛触角/螺旋壳，飞机机翼/座舱/螺旋桨，兔子耳朵/面部/滑板。均为原创Canvas绘制，不使用emoji或外部IP。半径尺度13–17左右，速度每毫秒0.017–0.052逻辑像素、三条高度、非均匀相位；不同速度自然超越。屏外循环，不产生点击目标。

## 瓶仓

盖子五组红、黄、紫、青、绿材质由(q×3+r×7)%5决定，不读取球类型；盖子的开关仍使用真实正面与洪泛暴露规则，不读取瞬时输入锁。下部遮挡使用完全不透明乳白暖光/淡紫渐变和很浅的中性槽位印迹，不能看出隐藏类别。

球半径上限从管半径0.78增为0.88，受可用垂直空间限制；高度预算使用实际压缩后的纵深，管容量不变。球槽间距仍为球直径，每球物理位置由开局槽位决定，取球后其余不移动。命中半径同步放大，仍小于球体且不超过单管范围。旋转仍绕固定束管中心，瓶壁与托盘保持。

## 验证范围

实际Chromium320/390画面检查首页、正面/侧边/背面字形动画、各面彩盖、取球前后、旋转与揭层。首轮发现转字部件拥挤，随后拉开间距再检查。只在本地保留截图，不作为用户美术偏好通过证明。

玩法、存储事务、单步撤销与广告适配未改。微信构建仅做模拟wx/Chromium Canvas桥接，未在微信开发者工具或真机运行。音乐未更改，未新增人工听测。生成器未改，300种子证据沿用v013，不把继承证据说成本轮新增运行。
