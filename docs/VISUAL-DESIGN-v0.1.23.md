# v0.1.23 粗边圆润标题与返回操作

基线 main `ecbe4de99a872d08f21ab9ba028fcf96ddc3438b`。本轮改动限于原创标题笔画、返回操作布局和测试/版本资料；保留背景、首页组件位置、随机开局、寄存规则、存档、单步撤销和音频生命周期。

## 标题

旧版字形骨架较窄，填色与描边的宽度差仅留下约1.75逻辑像素的暗边。新版本重画三字骨架并增大横向/纵向留白，圆头笔画配约3.25–3.5逻辑像素深棕轮廓，统一奶油金材质与少量高光。先改变笔画比例，再加粗轮廓，避免直接膨胀旧字形填死空隙。

“转”的横画行距拉开，“个”的两撇更饱满，“球”的王/求各笔画向球形轮廓组织；保留竖轴翻转，没有额外圆框或字体底板。320×568、320×660、390×844实际首页以及五个动画时刻均截图检查。竖轴翻转侧面必然变窄，不能承诺侧面和正面同样完整可读。

## 返回位置与触控

战绩页返回从底部 `height-100` 移到标题下左侧 `y=142`，空记录、满30条记录和分页保持一致。记录从214开始，分页固定在列表下方536，避免长屏把操作推至底部。难度与覆盖存档页返回改为内容下方、最高不超过460，不再随屏高继续下降。

所有 `返回`、`返回首页`、道具关闭按钮至少62逻辑像素高，绘制与命中使用同一矩形。模拟最短微信窗口320×568在胶囊下72及底部24预留后缩放，仍有约44.3屏幕像素的按钮高度。帮助面板同步增加底部承托空间。其他操作按钮沿用原尺寸，未删功能。

浏览器布局检查增加物理退出按钮高度≥44、底部留白≥32的断言，并执行点击。战绩夹具扩充为30条。原生构建wx模拟桥接另在三尺寸、空/满记录中点击返回中心上下16屏幕像素处，检查确实回到首页，而不只验证画布边界。胶囊与底部安全区为模拟值；不等同于用户真机手感验收。
