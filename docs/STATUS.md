## v0.1.2 实际反馈与修复证据

用户报告计时不走、一次取球后无响应。原 bundle 在“输入毫秒而固定除以1000”语义下复现完整症状，微秒语义下没有复现；用户已确认故障发生于微信开发者工具；具体工具版本与时钟返回单位仍未实测。证据见 `evidence/v0.1.2-bundle-reproduction.json`。因此本次结论是消除已证实的条件性故障路径，不冒称已诊断用户真机。

时钟现在在开局前采样校准单位并拒绝停滞源，活动时仍依赖单调时间。帧异常不会停止后续 RAF；故障切可见暂停；音频失败不影响事务。即时旋转不再进入 rotating 阶段。底部四个工具，默认直接点球，遮挡辅助面板按需显示。

新增两种单位下真实等待约10秒的独立对照、实际微信 bundle 连续输入与三预设通关、即时连转、暂停恢复、单帧渲染异常/音频异常/冻结时钟回归。浏览器 E2E 优先直接点击球，不再全部依赖底部标记完成；直接与辅助点击数量记录在 `evidence/e2e.json`。这些都不替代微信真机验收。

补充用户反馈：开场落球和取球移动极慢。已核对开场950ms与转移240ms均来自同一校准后的单调时钟；剩余管内球按已提交状态直接显示，无额外慢速补位计时器。新增实际 bundle 的独立墙钟测试覆盖完整开场、跳过立即ready、取球解锁与飞行球消失、剩余球位置稳定、连续第二次取球，以及两种单位下的启动冻结/开场冻结/转移冻结。模拟 wx API 与真实宿主计时不等同于安装的微信开发者工具实测。
