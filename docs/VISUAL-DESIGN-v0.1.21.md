# v0.1.21 清晰标题、道具入口、屏幕布局与首页音乐

基线 main `f2afab6`。本次不修改生成器、随机开局、奖励核销、三消计分或存档规则，保留免费单步撤销和无广告基础通关。

## 标题根因与重画

旧标题没有使用模糊滤镜。实际截图中，“转”的笔画中心间距常只有12–14单位，描边宽16单位，挤占字内空隙；阴影和高光又叠加到交叉区域。“个”的两条直线臂和直杆接近箭头，圆润程度不够。

重新绘制“转”的车/专结构：横画间距约18单位，描边12、主笔画8.5，曲线端点与转折留出空隙，缩短投影并重新对齐高光。“个”改为外鼓圆弧臂和圆头竖画，减薄挤出层，保留沿竖轴的间歇翻转。“球”仍由原有弯曲笔画构成圆形轮廓。全部为原创Canvas路径，不依赖中文字体加载或复制参考素材。

## 道具与布局

局内底部改为独立“寄存”小图标，不再常驻显示“广告未配置”。点击才打开说明：完整观看后移出末球，每局一次，之后可免费放回；需要再点击“看广告使用”才请求广告。未配置时说明广告暂不可用、次数不扣，只有关闭入口。空槽、已经使用、正在寄存各按真实状态呈现。说明期间暂停有效计时；取消返回原局，不能穿透点击棋盘。槽满页保留寄存入口、撤销、结束和返回首页。

有寄存球时显示真实球色和免费放回。广告取消、失败、重复回调、重启恢复的控制器逻辑不变；浏览器广告仍明确标注开发模拟，微信空配置不发奖。

所有按钮绘制（含边框、立体底边）收进实际命中矩形，逻辑高度至少52，重新留出工具栏/道具行间隔。难度页返回上移28单位；图示、战绩分页、覆盖确认、暂停和结算按钮同步检查。首页续玩与装饰跑道分离。

浏览器原先最低660像素画布在568高屏会被裁切；现在按可用高度等比缩放，并用同一比例反算点击坐标。微信继续使用原有胶囊/安全区避让和反算坐标，未占用系统区域。短屏物理尺寸随可用高度缩放，不能将逻辑尺寸当成所有设备上的物理像素尺寸。

## 首页音乐

进入首页即可尝试播放现有32秒、音量0.22的背景音乐。支持首页、开场和游戏过程，复用同一个播放器；静音偏好、暂停、后台、广告、结束状态保持安静。首页返回前台在允许时恢复，局内从后台回来仍保持游戏暂停，主动继续后播放。

自动播放被拒绝或播放器创建失败时不逐帧重试；下一次合法用户手势可以重试。静音和后台不会被手势重试逻辑绕过，旧播放Promise的迟到拒绝不会停掉新的播放。浏览器visibility/pagehide/pageshow与微信onHide/onShow均设置独立前后台状态，避免首页后台帧重新拉起音乐。

实际Chromium检查中初次自动播放被阻止（`initialPaused: true`），在首页点击帮助后播放成功，无需先开始游戏。未承诺所有平台无需交互一定有声音，未进行人工听感评审或真机音频验收。

## 验证范围

- 全量测试覆盖核心玩法、随机入口300种子、寄存道具300种子、存档与终局恢复、广告幂等及原生wx模拟。
- `layout-browser.mjs`：320×568、320×660、390×844，每种22个页面/状态；点击、边界、按钮重叠、取消覆盖和道具弹窗计时检查。战绩列表和终局截图使用明确标注的布局夹具，不代替真实通关。
- `lift-browser.mjs`：真实浏览器点击图标、广告确认、模拟取消/完成、刷新恢复、归还/单步撤销。
- `audio-browser.mjs`：实际HTMLAudioElement解码、32秒循环、首页手势重试、静音恢复、重复进局单播放器、广告静音；另有播放失败/前后台的单元测试。
- `native-canvas.mjs`：实际微信构建运行于Chromium的wx模拟桥接，三种尺寸绘制、胶囊安全区、道具不可用、暂停/继续/旋转；不是微信开发者工具。
- 三难度无广告真实点击通关另由E2E验证。构建、类型、格式及差异检查另行执行。

结果在 `evidence/v0.1.21-*`。本地截图以 `v021-layout-*`、`v021-current-native-*` 命名，PNG遵循仓库忽略规则。未测真实微信、手机、真实广告；推送main不代表微信审核上线。BlindBox未修改。
