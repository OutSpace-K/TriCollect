# v0.1.32 管束与转盘共享弧度

正面管底与转盘改用同一个椭圆模型。各朝向前排管底满足 `y = cy + ry * sqrt(1 - ((x-cx)/rx)^2)`，转盘盘面在同一中心和水平半径下至少留8个逻辑像素的边缘余量；旋转中途按完整固定管阵列扩充装饰盘面，防止朝前的角管脚落到盘外。不是只让管子更弯、再独立移动托盘。

管束以原世界坐标旋转后进入该投影，画面、球、点击、飞行起点共用point函数。采用完整固定管阵列计算中心修正，不会因取走球改变弧形或盘面宽度；球径、横向间距、俯视纵深0.52与可见/取球规则不变。转盘素材整张缩放，根据原图盘面约占72%的比例匹配椭圆，避免切开箭头和金扣产生接缝。

## 验证

- 三个正式朝向的前排管底与共享椭圆逐点相等。
- 四尺寸×三难度×三朝向：合法顶球命中、隐藏/下层阻止及一次真实取球。
- 全周每1°采样的336,960次管体边界检查。
- 微信bundle完整取球/旋转胜利路径与全量回归。
- 300种子可解见证；72组精灵/回退隐藏颜色像素不变检查。
