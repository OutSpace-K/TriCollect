# v0.1.16 瓶塞、体积与短锁反馈

## 实现

首页“转”为900字重的系统字体填充，避免只靠厚描边；“个”在9秒周期中的1.6秒绕自身中心转一周，其余时间保持直立。最后一字笔画与圆形墨迹轮廓连接，无圆形底板。跑道六个球/玩具使用不同相位、三条高度与不同速度单向循环，屏幕外衔接，无点击区域；后台及弹窗不累计装饰时间。

瓶束排列纵深从原始投影的0.62恢复到0.8，仍保留较低三角形视图和中心轴。球径、固定槽位和真实容量不改。管壁侧面连续明暗、顶部椭圆内壁、薄边高光和托盘厚边形成体积；没有实时3D物理光照或折射。

每根占用管的盖子依据faceVisible的真实正面与外部连通暴露结果。不可访问管绘制金色顶面、侧带和接触阴影，其他管开口。旋转中隐藏球与目标，但盖子不因为全局输入锁全部关闭；取球短锁同样不改变盖子语义。清空外层后重新计算，内层可访问时开盖。后管从不绘真实球类型。

按钮把disabled（拒绝操作）和dimmed（灰色表现）分开。resolving/rotating短锁期间保留原色；真实无撤销记录仍灰。输入控制器没有放宽：重复取球、动画中旋转和撤销不会进入第二次动作。

## 实际像素与交互

Chromium的320和390宽实际页面已打开检查：首页静止与“个”半圈、三面瓶塞、转动中管束、取球前后底栏、几何揭层、不同高度与窄屏。初次第一字路径过于团块，已改成真正粗体系统字并重新看图。截图只作内部检查，不包含在源码包。

ui016.mjs检查三面盖子与真实可访问集合一致；取球期间盖子状态不抖动；两次连续取球后，整个底栏区域与取球前像素逐字节相等，且短锁仍拒绝重复取球/旋转/撤销。第一次取球使原本无撤销能力的按钮变为可用色是正常状态变化。几何专用夹具清空阻挡管后验证内部1,1开盖，此夹具不是随机生成或通关证据。

home015.mjs在当前版本检查隐藏类型修改后画面像素不变、未完成局不被难度弹窗覆盖、循环边界及后台恢复。浏览器三档105/126/216次直接点击全部无广告通关，无辅助取球。微信构建在Chromium Canvas桥接验证，仅为模拟wx接口，不等同微信开发者工具或真机。
