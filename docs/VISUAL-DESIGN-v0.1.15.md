# v0.1.15 首页与玻璃呈现

首页沿用中央瓶球展示、下方主入口的层级，难度从两侧撤出。开始按钮只打开选择弹窗，不启动或保存新局；三档同列展示，返回保持原状态。有未完成局时，选难度后先显示替换确认，继续上次和返回均不会覆盖它。

标题继续使用原创路径而非普通字体阴影：转字加粗，个字保持直立沿小圆轨迹移动，轨道点强化方向；球字融入金色光泽球体。跑道含原创玩具车与彩球，统一左到右，边界在屏幕外循环，完全不参与碰撞或点击。动画使用独立累计呈现时间，后台停止累计，回前台首帧不补算离线时间；弹窗期间装饰停止。

正面玻璃上部透明、下部磨砂有色、不透明底色和细反光带，淡淡轮廓不带球类别。取走顶部球后，最多3颗真实颜色的观察区域逐层下降；所有球依然在开局原槽位。后排只绘低对比实体轮廓、开口与投影；这是细节和对比度简化，不声称真实景深或物理折射。旋转中仍无可选球和真实背面类别。

实际检查：320×660/390×844首页前后、标题不同动画帧、三档弹窗、替换确认、三个面/混合高度、旋转中、内层揭开、暂停/结算。`tests/home015.mjs` 用真实Chromium截图比较，改变所有隐藏球的类型后球仓像素完全一致；该颜色替换仅是图像隔离夹具，不作为合法对局/保存证据。`tests/variable-visual.mjs` 检查剩余球坐标，真实合法直接点击通关由 `tests/e2e.mjs` 执行。

95项Node/模拟微信回归通过，真实微信开发者工具/设备没有运行。视觉偏好、真实触摸与人类难度仍需试玩。v0.1.14终局一致性及存储配额修复未改动。
