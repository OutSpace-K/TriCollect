# v0.1.19 圆润标题与广告寄存球

基线为最新 main `3669e21`，本环境重新实现、重新验证；不继承旧环境未提交代码或测试结论。

## 体验

去掉开局准备页“开始”旁的玩法/新手按钮，开始按钮扩宽；首页顶部玩法仍可打开三步图示。标题沿用原创手绘汉字路径，以圆头圆角、奶油描边、柔和绿色/橙色渐变和细高光表达果冻质感，没有复制参考游戏素材。跑道五类玩具放大，增加轻微弹跳与横纵反向缩放；后台和弹窗仍冻结装饰时间。

局内底部和槽满弹窗提供自愿“看广告 · 移出末球”。完整观看才将最后一颗暂存球移到单独寄存位，每局成功一次，继续后可免费放回。选择末球是明确、可预期的当前规则，不是任意选择球或永久删除。放回按原三消规则结算，可能重新填满七格；可免费单步撤销。奖励发放会清除奖励前的撤销快照，后续取球与放回仍支持一次撤销，防止撤销跨奖励边界造成重复球。

寄存球仍参与身份、总数、存档和胜利校验。求解器将免费放回作为合法动作；需要放回时提示明确说明。五分钟基础时间、续时上限、原取球和遮挡规则、计分保持不变。不看广告仍有生成时验证的通关路线。

## 广告与恢复

复用微信激励视频适配器，只有 `onClose({isEnded:true})` 完成证据发奖。未配置、初始化失败、取消、异常均不发奖。浏览器仍明确弹出开发模拟提示，不能证明真实广告有效。

奖励记录新增可选 `kind`；旧记录缺省为续时，旧存档缺省无寄存球。新奖励不会增加续时次数或秒数。请求期间拒绝重复请求和新局覆盖；同一会话奖励只核销一次。重启时未完成请求转失败，已完成奖励与寄存球一同恢复。新存档继续使用原校验和、读回校验和终局事务；无新服务器。

## 随机排列说明

`Controller.start()` 未传种子时使用该难度固定默认种子；首页重复选同一难度会得到相同布局。结算“再来一局”传入 `(seed + 1) >>> 0`，因此会换确定性种子。生成器先构造合法几何取球路线，再按难度窗口分配、打乱成组三同颜色，逐局回放见证解；生成异常回退默认种子。

32位随机种子空间为 2^32，但不是已证明的 2^32 个独立布局：种子到布局可能碰撞，不同种子也可能得到同一颜色排列，回退也会重复。当前没有固定预制关卡列表，也没有统计所有独立布局数量；300种子测试只验证样本正确性。
