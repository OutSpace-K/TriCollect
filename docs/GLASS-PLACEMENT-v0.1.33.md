# v0.1.33 玻璃管与盘面落位

## 实现

- 参照已确认提案重新生成透明玻璃管贴图，细暖粉玻璃边、椭圆开口与底足。顶底保持比例，中间拉伸；中段只叠加最外侧边条，避免素材白色反光遮住圆球。
- 隐藏球始终不绘制。内芯的背景采样/雾化与隐藏球身份无关，不借用真实后排颜色，因此不会泄露下层球色。
- 托盘按实际奶油面锚点对齐，不再使用图高72%的猜测。足底按椭圆完整轮廓而非仅中心计算落位，保留原球径、旋转与命中投影。
- 图像加载失败保留程序绘制回退，微信和网页共用素材。

## 与视觉提案的必要差异

提案画的是三球高、全透明、少量容器。真实玩法每管容量5–7球，且只显示可见窗口；为保留规则和大球，真实管束更高、更密，隐藏区域没有彩球。不能宣称与提案逐像素一致。

## 验证边界

实际预览来自生产Scene离屏Canvas绘制，不是替换游戏画面的效果图。自动化检查覆盖多尺寸命中、旋转投影、隐藏颜色像素不变和可解种子。不等同微信开发者工具或真实手机触摸、帧率及听测；未自动上传微信体验版。

## 本次结果

- 构建、类型检查和格式检查通过；193项全量回归通过。
- 300种子全部完成合法无广告见证解并保持球身份守恒。
- 72渲染场景、9288次隐藏颜色变化保持逐像素一致；4种屏幕×3难度×3视图的命中检查及逐度旋转完整足底检查通过。
- 普通、困难和旋转中间态实际截图已检查。为保留球尺寸，盘面左右外沿仍略有裁切；薄粉玻璃轮廓与提案也有质感差异。
