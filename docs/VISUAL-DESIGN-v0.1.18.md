# v0.1.18 原创陈列场景与统一页面

## 场景与页面系统

采用米色房间、彩色饮料货架、蓝色搪瓷桌面与地砖的原创陈列场景。背景边缘有棚沿、瓶子、植物和柔光；中央陈列位保持安静，玩法对象与背景对比清楚。两张实际PNG由 `scripts/make-showroom-backgrounds.py` 程序绘制，分别进入首页与局内以及两端构建，不使用第三方截图。

黄色主按钮、蓝色次按钮、奶白内容面板、深蓝边框统一首页/难度/战绩/暂停/结算/图示说明。局内仅时间、清空进度、难度和必要操作，不新增虚构关卡或商业入口。准备页可打开三步图示，覆盖顶部取球、三同消除与免费旋转/撤销/提示；关闭返回原准备状态，不启动计时。通关彩纸仅为2.6秒有限视觉反馈，暂停后台不会积累时间或重复发奖。

参考网页： https://www.yx007.com/azyx/186363.html 。本执行环境无法直接打开该来源，网页请求返回 `Tunnel connection failed: 403 Forbidden`；设计依据来自已提供的实际教程截图观察：米黄地面、蓝桌、饮料柜、透明瓶口、左侧高光和少量黄/灰工具。宣传外框与横幅不作为实际操作界面。未下载游戏，未复制素材或文案，也未通过其他路线绕过网络限制。这里不能声称已在本环境直接查看参考原图。

## 字形、动线与材质

转字沿用原创粗笔画形状，添加13.5像素黑色外描边与轻微下方厚度，彩色内笔画9.5像素。个字仍使用逐点竖轴透视投影，增加8层挤出、深绿侧面和窄亮面；不是平面旋转。球字不增加外圆，保持笔画构成的圆形轮廓。

旧跑道三层中心只有9/7像素差，实际物件高度使其看起来挤成一排。本版三层距屏底90/52/20像素，相差38/32像素。顶部、底部向右，中层向左并镜像朝向；五类原创建模玩具尺度不同。中层平均速度0.046，顶部0.027，底部0.017逻辑像素/毫秒。同层配对相位相差半圈，叠加幅度8–12像素的平滑微动，形成不同即时速度且不会不断追尾。取模支持负向跨屏，接续发生在屏幕外。

为避免最上层遮住继续按钮，开始按钮上移，继续入口保持独立，窄屏底部留112像素装饰区域。所有装饰保持后台/弹窗暂停，不产生点击目标。实际32秒采样覆盖最慢物件完成一圈，并检查同层间隔。

隐藏区取消淡影球圆形和淡紫实块，换为不透明琥珀色棱纹套层。亮面朝左前，右侧暗部、弧形口沿和细竖纹增加体积；上部玻璃反光保留。它只遮住未露出球的位置，揭露边界随取顶下降，不推移剩球。颜色不读取任何球类型，修改隐藏类型后的画面像素必须完全相同。

## 实际检查与边界

实际Chromium320/390截图检查标题正面、半圈与侧面；跑道0/4/11/22/32秒；三面彩盖、转动中、揭层、不同容量与取球前后。首页原图和上版截图用于对照，截图仅内部使用。

规则、球半径与命中区域、300秒有效计时、单步撤销不返时间、终局事务、本机30条战绩均不改。生成器未改，沿用v013的300种子证据，不把它说成本版新增回放。

Canvas2.5D材质与挤出是绘制表现，不是实时3D引擎。真实微信开发者工具、手机触摸/性能和用户美术偏好待验收。音乐未更改，无新增听测结论。

新增图示遮挡输入、已读持久化/失败降级、准备页不计时、彩纸有限时长与后台恢复、广告初始化异常降级均有回归。正式验收记录以 evidence 中最终结果为准。
