# v0.1.22 寄存位置、稳定按钮与统一标题/背景

基线 main `1a13cc7`。不改变取球、随机种子、广告核销、单步撤销、存档或音乐规则。

## 寄存入口与动画

寄存/免费放回从操作行下方移到暂存槽上方靠左（x=22），与暂存槽、四个操作按钮保持独立行。收回原下方道具行的空白，暂存槽下移，取球飞行动画终点同步指向新的槽位高度。

闪灰根因是寄存按钮没有像左右转/撤销/提示一样区分 `disabled` 和 `dimmed`：取球与转面动画会锁输入，同时自动走灰色样式。现在 resolving/rotating 只锁交互、不置灰，寄存和放回都适用；准备阶段或真正不可用状态仍保持对应视觉，未放开重复请求、重复归还或动画穿透。

新增 `tests/tool-motion.mjs` 在320×568和390×844截取按钮像素区域，比较取球和转面前后完全一致，并在锁定期间实际点击确认棋盘、奖励和弹窗状态不变。单元测试另覆盖两种入口的 disabled/dimmed、相对槽位位置及解锁恢复。

## 首页与标题参考

标题、中央瓶球展示、眼睛球角色、开始按钮统一下移16个逻辑像素，原相对间隔保持。续玩按钮跟随主入口；短屏有续玩时仅收紧装饰跑道纵向层次，保留玩具大小、五类形象和交互入口，不遮盖续玩按钮。

主线程已实际查看三组参考图片并提供观察；本执行线程核验以下来源页面及图片链接，未把第三方画面、字形或角色复制到工程：

- [开心消消乐，小米游戏中心页面](https://game.xiaomi.com/viewpoint/1399693245_1641455711550_3)：提炼饱满暖黄橙、清楚内外轮廓和少量高光。
- [羊了个羊截图所在的每经网报道](https://www.nbd.com.cn/articles/2022-09-28/2483741.html)：提炼粗字、对比轮廓和简单阴影。
- [抓大鹅案例页面](https://www.netmarvel.com/news/874.html)：提炼圆粗字、细深轮廓和单一主题细节。

这是视觉样例研究，不是当前热度排行或照搬字形。最终使用本项目原创Canvas笔画：三字统一奶油黄/暖金渐变、细暖棕轮廓、单层轻影和少量高光；“个”稍低、“球”略错落，避免三种材质混用。保留“个”绕竖轴、球字笔画自身形成圆形轮廓，没有外加圆框；减少“个”的挤出厚度。320/390与矮屏检查正面及五个动画时刻；侧面时“个”按竖轴投影变薄，竖画仍可见，并非承诺所有角度都像正面一样完整可读。

## 背景资产

以仓库既有原创货架/棚沿/桌面/地砖图片为底，通过ImageGen改绘两张背景：饮料、标签替换为透明瓶中2–3颗彩球，保持首页中央留白与局内较高桌面，两张统一为柔和玩具玻璃质感。未使用上述游戏截图作背景生成参考。生成原图保留在执行环境，发布PNG仅做600×1040资产缩放，约464/447KB；构建包包含更新后的两端资源。

`assets/background-provenance.json` 记录源图与最终资产哈希及处理方式。历史 `make-showroom-backgrounds.py` 只能重建旧版程序背景，不能精确重建这次生成式改绘，不应把它当作当前PNG的完整重制脚本。
