# v0.1.12 实物桌面与首页入口布局

本版重点是首页的空间层级与功能键分布。中央保留转个“球”的标题与瓶球主视觉，下方只突出一个橙色开始按钮；探索、深入两个已有难度入口分散到主视觉两侧，音量在右上，继续存档按需出现在开始按钮下方。没有新增收集图鉴、签到、排行榜、邀请或商城。

[7K7K抓大鹅页面](https://www.7k7k.com/wxgame/5.htm)是局内参考，不能替代首页研究，其原图也抓取受限。补充的[抓大鹅玩法截图页面](https://www.doyo.cn/game/471513.html)和[玩法说明截图](https://www.dancihu.com/article/51342.html)帮助区分容器/物件视觉与宣传框。没有复制素材、鹅形象、商标、截图或玩法。

## 原创实现

- 场景：安静的青绿色哑光桌面，左前方日光；去掉霓虹框、发光舞台和深紫面板。
- 首页：放大的玻璃瓶和彩球置于有厚度、下投影的木质展示台，侧键与主视觉不重叠。
- 局内：玻璃瓶口与透明观察窗、鲜亮抛光球、较深接触阴影；木质三角承托与整束共同旋转。
- 收集槽：白色搪瓷盘、厚边、七个带内壁渐变阴影的凹槽，保持原输入和容量。
- 暂停/结算：浅色卡片、木色边沿、深绿文字与同一套实体按钮；广告标识和异常反馈保留。
- 隐藏球：中性灰绿色体积，没有真实类别；固定槽位、最多三颗实色、只取正面顶球不变。

背景PNG由 `scripts/make-tabletop-backgrounds.py` 原创离线生成，无外部素材；旧脚本保留历史用途。字体使用系统字体。表现仍是Canvas 2.5D，不是实时物理渲染或真3D。
