# v0.1.11 视觉系统

目标：从浅色原型面板改为蓝紫街机陈列台。屏幕重心是亮面彩球与玻璃瓶束；高饱和按钮承担操作层级，背景保持低亮度，不使用满屏粒子或杂乱纹理。

| 元素     | 设计                                     |
| -------- | ---------------------------------------- |
| 主场景   | 深蓝紫空间，低对比建筑框与透视台面       |
| 主要操作 | 柠檬黄面、深色文字、橙色厚度和深蓝外轮廓 |
| 次级操作 | 亮紫面、白字、深紫厚度；失效用低饱和灰蓝 |
| 玻璃瓶   | 浅青双层广口、纵向左前反光、底部折光     |
| 彩球     | 连续饱和渐变、镜面高光；没有选择红圈     |
| 隐藏球   | 统一蓝灰阴影体，不含类别或符号           |
| 浮层     | 同一深蓝卡片、亮色徽章、主要动作突出     |

首页保留特效字和放大的三瓶主视觉，单个主入口加两个次级难度入口；继续存档按需出现。删除版本、种子、管编号、重复说明与道具使用次数。局内只留时间、清空进度、三面位置短条、暂停/音量和四个底部工具。提示仍直接作用于球仓，不新增弹窗或按钮。开场保留一句“点顶球 · 三颗同色消除”，失败、搜索未知、存档异常与广告标识仍显示。

暂停、槽满、超时、等待广告和结算使用统一卡片；暂停遮住棋盘。广告保留“看广告 +30秒”和开发模拟标识，不伪装免费奖励。浅三角托盘仅装饰，瓶束投影和固定球槽规则不变。

## 资源与验收边界

两个600×1040背景PNG均由本项目原创离线脚本 `scripts/make-arcade-backgrounds.py` 绘制；不含外部图片。首页与局内分别加载图片，失败时使用深蓝底色，不阻塞操作。音乐沿用上一版。

实际Chromium检查首页、开场、进行中、三面、旋转中、误触、内层、暂停、槽满、超时、广告等待、成功和失败，覆盖390及320宽屏。浮层截图可注入状态，不能作为通关证据；真正的三预设直接点击通关另见e2e记录。截图内部保存，不进入源码包。

表现仍为Canvas 2.5D，不是实时3D折射。界面审美、微信开发者工具/真机安全区与性能仍需要实际试玩；模拟和浏览器检查不能代替这些验收。

微信入口读取系统胶囊下沿并预留8像素；接口缺失/异常时按状态栏下方44像素回退，底部保留安全区。绘制和触摸使用相同缩放变换。另以真实微信game.js在Chromium Canvas与wx适配层运行，检查320/390宽度的像素、安全间距、开始/暂停/恢复/旋转；这仍不是实际微信工具。首页主视觉的Canvas状态在异常时也通过finally恢复。
