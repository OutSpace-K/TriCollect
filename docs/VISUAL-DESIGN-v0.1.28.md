# v0.1.28 玩具店视觉与交互验证

## 最终实现

- 用户确认的第二版：立体彩色标题、透明首页装饰英雄图、两套玩具店插画背景均作为实际素材加载，不用概念图冒充游戏运行画面。素材失败时保留程序绘制回退。
- 控件：厚奶白边、亮绿主按钮、弯箭头与中文旋转标签、棕色计时器、蓝色进度条、奶油暂存槽。
- 转盘：珊瑚橙立体底座；前缘恢复白边红色左右弯箭头，仅装饰，不新增点击目标。
- 俯视：恢复音乐版 v0.1.27 的纵深系数0.52，世界坐标、刚性旋转和遮挡规则不变。通过减少纵向留白、增加可用管高与球/管径比保持比旧版更大的球，不靠压平视角伪造放大。
- 玩法：各难度管数、球数、容量、前三球可见、合法顶球选择、七格暂存、撤销和可解生成均不改。下层颜色必须遮挡，与概念图的全透明短陈列管不同。
- 保留 v0.1.27 音乐修复，不改AppID、广告位和存档规则。

## 验证

实际Scene离屏渲染覆盖320×568、360×640、390×844、430×932首页、普通/困难游戏页与弹窗。顶底黑区为模拟安全区，不是游戏遮挡。预览是实际代码渲染，但不是微信真机截图。

可复现：安装可选@napi-rs/canvas后执行 `node --import tsx tests/proposal-render.ts`，或用 `TRICOLLECT_CANVAS_MODULE` 指向已安装模块；设置 `TRICOLLECT_PREVIEW_NORMAL=1` 输出普通模式。

全量单测覆盖微信构建入口、时钟、旋转、保存、音乐生命周期；另有300种子完整胜利路径及球身份守恒检查。球尺寸、最终日志在 `evidence/v0.1.28/`。视角恢复后，以 `ball-size.json` 的最终测量为准，不沿用早期扁平视角的44%增幅。

## 边界

Chromium在本环境因socket权限无法启动，故未声称浏览器端到端通过。微信手机真机触控手感、胶囊安全区、动画帧率、音乐听感仍待体验版验证。推送仓库不等于上传微信体验版。
