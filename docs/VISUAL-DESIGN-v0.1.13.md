# v0.1.13 页面与难度变化

首页继续使用 v0.1.12 已研究的中央主视觉、侧边次级入口和下方主按钮布局。没有新增第三方图像；参考来源及访问限制保留在前版设计记录中。

本版标题用原创Canvas路径构造转/个/球字形，圆润笔画、奶油边缘与翠绿/橙黄填色，有轻微不同倾角。中央装饰球有眨眼和5px以内浮动，使用受保护的单调时间，仅首页生效。左上战绩/玩法、右上音量，三个难度清晰命名，继续存档按需显示。记录弹窗明确“仅本机”，没有假好友榜。

局内PNG加入侧窗、窗台、植物、边缘菱形与木质地面，中央不画花纹。深蓝亮面阴影球采用固定中性色渐变，无真实类型参数、无符号，反光与轮廓只表达体积。玻璃瓶口和统一左前光保留。

不同高度由实际不可变capacity决定：简单全5；普通/困难5、6、7均匀交替。球半径和槽距由全盘最大初始容量统一计算，空掉最高管后不重排，不对球做纵向压缩。后管即使高过前管也只显示中性影，不跨越前排点击。顶部命中、飞行起点、撤销和存档仍使用原球ID/槽位。
