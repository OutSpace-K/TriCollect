# v0.1.31 对照确认提案重制

## 实际改动

- 转盘不再仅使用平面程序椭圆：按确认提案生成独立透明素材，包含珊瑚红立体侧面、奶油盘面、白边弯箭头和中央金色扣件；实际游戏合成在动态管束后，未把整张提案当作游戏。
- 七色球重新按提案的红、橙、黄、紫、蓝、粉、绿制作，使用较小高光、饱满暗部和柔和亮边。视觉上原青绿色类型改为橙色，类型ID、配对与存档仍相同。正常精灵分支去掉球面图形标记，以接近提案；加载失败的回退仍可用。
- 正面管口改为细玻璃沿、管身改直筒，去掉瓶肩。后排封盖统一暖奶油色，但保留不可访问管的封闭状态表达。
- 隐藏段不再有金属条纹、紫白套筒接缝和粗底环，改成连续玻璃中的暖奶油柔雾。固定不透明遮挡完全不读取下层球类型。
- 球大小、弧度、俯视纵深、世界旋转和点击规则保持不变。

## 不能宣称逐像素复刻

提案画的是每管3球的矮透明陈列，实际规则为每管5–7球、仅展示前3球，其余必须隐藏；因此实际管束更高且有明显遮挡面积。真实手机纵横比也与概念图不同。这是现有规则与概念构图的差异，不是微信必然无法绘制好看的球。若要完全照提案变成矮透明管，需另外批准改变容量/隐藏规则，或重新制定与现有规则一致的美术提案。

去掉球面标记使外观接近提案，但仅依靠颜色识别，对色觉差异用户的辅助弱于旧版。没有宣称已经达到无障碍验收。

## 验证边界

全量回归包括微信构建入口、精灵加载失败、三难度完整取球胜利、旋转及模拟触摸。额外像素审计覆盖4尺寸×3难度×3朝向×精灵/回退，加载实际背景和转盘，修改隐藏颜色后画面必须完全相同。渲染比较每次清理完整画布并保存/恢复上下文，以隔离分数像素边界的帧间积累，而不忽略绘图区差异。
