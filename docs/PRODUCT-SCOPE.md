# 当前功能与产品术语（v0.1.21）

| 术语                | 含义                   | 当前实现                                                                                     |
| ------------------- | ---------------------- | -------------------------------------------------------------------------------------------- |
| UI / UX             | 界面视觉 / 操作体验    | 原创陈列场景，统一按钮面板，首页/局内/难度/暂停/结算/战绩/玩法                               |
| HUD                 | 对局中的关键信息区     | 时间、实际清空进度、难度，非虚构关卡号                                                       |
| Core Loop           | 核心重复玩法           | 旋转观察→正面顶球入槽→三同消除→清空外层揭内层                                                |
| FTUE                | 首次使用引导           | 可选三步图示与本机已读偏好；尚非可操作的教学关卡                                             |
| Booster             | 辅助道具               | 免费单步撤销、免费预算求解提示；自愿广告寄存末球后免费放回，无背包/购买/扩槽                 |
| Rewarded Video / RV | 玩家自愿观看的激励视频 | 微信接口适配已写，真实广告位/AppID未配置；超时续30秒最多2次、寄存末球每局1次，完成回调才兑付 |
| Meta progression    | 局外长期成长           | 未实现关卡地图、解锁、升级、收藏与货币                                                       |
| LiveOps             | 持续运营活动           | 未实现签到、任务、赛季、远程活动配置                                                         |
| Analytics / Funnel  | 埋点 / 转化漏斗        | 未接入服务端统计、广告收益分析或A/B实验                                                      |

## 已有边界

三档105/126/216球，全部300秒，逐局生成并回放见证解，无广告基础通关路径。首页确认新局使用随机种子，继续存档保持原种子，结算再来递增种子；不是多关卡解锁系统。人类操作难度与300秒节奏仍需试玩。

本机最多30局正式战绩、进行中存档、校验备份与终局暂存恢复；未完成局不是战绩。没有账号、云同步、好友榜或开放数据域，不能编造好友数据。真实好友排名的条件见 FRIEND-RANKING.md。

微信构建与浏览器模拟广告隔离；空配置或创建异常不阻塞游戏、不模拟生产发奖。没有横幅、插屏、支付、强制观看或服务器经济系统。任何新增改球规则、消耗型道具或商业参数需要先确定设计、可解性与验收方法。

本版彩纸是视觉反馈，不是金币或额外权益。参考只用于视觉层级与材质规律，素材全部原创，当前仍为Canvas 2.5D。
