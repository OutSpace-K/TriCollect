# v0.1.34 手绘隐藏区与圆管视觉

前排隐藏区共同显示一幅画，按圆柱曲面映射。画面框架基于固定槽位与容量，取球仅缩小窗口；旋转期间沿用遮挡保护，结束后新前排重组画面。没有改变球数、胜负、可解种子或取球规则。球距从2r缩至1.94r，球大小保持；命中仍以合法顶球为准。

## 离线随机组合

四幅明显不同的手绘底图，16种水平构图×8档缩放×2镜像×8轻色调，共8192个配置编号。新开局避免最近64个编号，且不连续使用同一底图；保存/继续/撤销/旋转不重选。旧档确定性补全编号。组合不等于8192幅全新画，仍可能近似，全部有限，非联网AI逐局生成。

## 性能与安全

每局合成一次，管壁映射缓存最多128项/16MiB，暖缓存每管一次绘图。素材仅绘入不透明隐藏窗口，绘图不读取隐藏球颜色。失败回退原绘制/不透明底色。

## 验证边界

真实Scene离屏Canvas画面、自动化状态/点击/多尺寸/隐藏色像素检查；未进行微信真机上传、帧率和触摸实测。发布报告以最终测试结果为准。
