# v0.1.37 分难度时长

- 新开局：简单2分钟（120秒）、普通3分钟（180秒）、困难4分钟（240秒）。重开同一难度也采用对应时长。
- 开始前不计时；开始按钮、难度选择说明及玩法文字同步，实际倒计时按局内剩余时间显示。
- 免费加时仍每次30秒、每局最多两次。寄存、撤销、提示、球数、消除、旋转和无广告模式不变。
- 每局保存独立baseMs；更新前缺少该字段的旧存档按原5分钟预算继续，不重置或扣减旧局剩余时间。更新后另开新局才使用2/3/4分钟。
- 战绩耗时使用该局基础预算+已加时−剩余时间；旧战绩保持原兼容上限。
- 保留backup/v0.1.35，不更新其分支。源码/构建发布不等于微信上传审核或真机验收。
