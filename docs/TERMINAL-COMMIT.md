# 终局与战绩的一致性（v0.1.14）

v0.1.13 的失败路径：结束时主存档写失败，战绩却成功；重启恢复旧活动存档，同一 session 可继续。再次获胜后，旧战绩的会话去重阻止更新。

补丁使用单个待提交终局 `tricollect.terminal.v1`，保存经过原存档校验的最终棋盘、时间、分数和奖励账本（终局不再保存不可使用的撤销历史），带校验和。先写入并读回校验，再尝试主存档与战绩；主存档现在也读回校验，静默丢写不算成功。终局暂存与主存档至少有一处成功持久化，才允许记录战绩。主存档、战绩均成功后才清除暂存。清除失败仍保留幂等重试。

启动首先恢复待提交终局，补齐主存档和战绩；未提交完整之前不恢复旧活动局、不允许新局覆盖它。若暂存写失败但主存档成功，终局主存档成为恢复依据；战绩失败可在重启或新局前补写。暂存不可读取/校验失败时保留原数据并阻止危险恢复，不自动删除。

v0.1.13 已产生的“旧活动存档+同session战绩”直接视为已结束，不允许继续，不删除战绩。如果已有经过校验的完整获胜终局与旧失败战绩冲突，可将该条更正为获胜，不新增重复条目、不将获胜降级。

所有写入都失败时没有任何系统能保证强制退出后保留新数据。本补丁不宣称保存成功、不追加虚假战绩，保留当前内存终局并阻止离开结算/开启新局，写入恢复后可再次操作重试。若此时进程被强制终止，未持久化终局仍可能丢失；界面明确提示存档或战绩失败。

本补丁不改变规则版本、画面、声音、300秒、难度或本机30条上限；v0.1.13进行中存档兼容，更旧规则仍提示重新开始。没有删除或重置用户记录，没有云同步或好友榜变更。

配额回归：困难档216步撤销历史若连同终局再次复制，会触及浏览器存储配额。终局压缩不修改内存棋盘或局内撤销，只省略持久化终局的历史快照；新增30KB终局单键限额测试及实际浏览器全档通关。

活动存档仅持久化最近一步撤销快照，保留单步撤销及序列号；内存操作记录不变。旧存档仍能读取，后续保存自然收敛大小，避免主/备份/临时文件复制整局历史挤满配额。
