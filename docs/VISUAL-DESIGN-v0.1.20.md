# v0.1.20 随机开局与清晰标题

基线 main `59bcf5a`。首页确认难度且无待续局时立即生成随机种子；有存档时必须确认替换才生成。仅打开难度、关闭弹窗、取消覆盖或继续上次均不调用种子随机源、不更改原棋盘或种子。存档失败和终局提交的既有保护先执行，之后才生成新局。

种子使用 `Math.random` 的32位映射；随机源抛错、非有限数或越界时回退时间种子。排除当前局、可恢复存档和本运行实例最近256个首页种子，发生碰撞按32位递增跳过，固定返回值也不会使近期新局反复相同。重启至少排除有效存档的种子；本机存储完全不可用时无法跨重启记住历史。生成器仍逐局验证见证解，并保留原有回退；若回退产生被排除种子，最多重试8次，失败保留原局并显示失败提示。

同种子仍可确定性复现，显式种子接口保留以支持测试和回放；结算“再来一局”仍将当前种子加一。32位种子不代表同数量的独立布局，历史超过近期窗口也可能重复，不承诺所有新局布局绝不相同。

“转”字改为珊瑚粉红至莓红渐变，浅奶油边、深莓红轻投影及柔和高光，明显区别绿色“个”。缩细内笔画和描边，打开字内空隙；继续使用原创圆角路径，无外部字体或素材。实际检查320×660与390×844首页截图，保留果冻感。

验证包括：最终代码全量测试；300个随机首页入口种子的三档见证通关；原移球广告300种子专项；广告取消/失败/未配置/重复回调与重启；保存/恢复/取消覆盖；Chromium三档实际点击无广告通关；320/390宽广告、刷新、归还与单步撤销；原生wx模拟回归。随机化后浏览器和原生测试从当前真实存档种子取得见证路线，不再假定默认局面。

证据位于 `evidence/v0.1.20-*`，截图在本地 `evidence/v020-home-320.png`、`v020-home-390.png` 等（PNG按仓库规范忽略）。未测微信开发者工具、真实手机或真实广告；推送main不等于微信审核发布。没有修改BlindBox。
