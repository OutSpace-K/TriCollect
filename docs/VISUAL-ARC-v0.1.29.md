# v0.1.29 正面管束柔和弧形

正面各管底部呈浅弧：中间稍靠前、两侧稍后退，常见屏幕两端与中心差约7–10个逻辑像素。保留v0.1.28的俯视纵深0.52、球径、水平间距、转盘箭头与背景素材。

实现为世界坐标旋转后的对称浅弧投影，所有管、球、选择范围、点击坐标和飞行动画起点共用同一point函数。不是只移动贴图，也没有改动棋盘拓扑或合法取球规则。均值修正保持束中心稳定；旋转全周连续，横向投影与球尺寸不变。转盘边界取完整固定管束，避免中间弧段超出盘面。

自动验证覆盖四尺寸、三难度、三个朝向的顶球命中/下层遮挡，完整旋转每1°边界检查，以及微信bundle完整取球胜利路径。300种子胜利见证均通过。新增浅弧对称、弯曲上限与转动中球径不变测试。原有回归继续覆盖存档、撤销、时钟与音乐。
